# React Live Coding Intro

## Installing and starting the app

- Note that I use [pnpm](https://pnpm.io/) as a package manager, but npm or yarn should work too.

**Step 1: Backend**

- From the `backend` folder, run:

1. `pnpm install` 
2. `pnpm start`

The backend runs on http://localhost:7100

**Step 2: React SPA**

The `workspace` folder contains a react SPA based on Vite.

From that folder, run:

1. `pnpm install`
2. `pnpm dev`

That starts the development server on http://localhost:3000

**Step 3: Next.js app**

The `workspace-nextjs` folder contains (almost) the same app, but as a Next.js Fullstack Application with React Server Components (RSC)

From `workspace-nextjs` folder, run:

1. `pnpm install`
2. `pnpm dev`

That starts the Next.js server on http://localhost:3100
